B. 已採購 PBN 高權重域名（試水溫，僅 NT$1,197）

策略目的：DR 是 Google 排名的第一道門檻，新站沒有 DR 就算寫再好的內容也很難出現在第一頁。 PBN（私人部落格網路）的做法是：買入已有真實歷史與 DR 的老域名，在上面發布相關主題文章並連結到 ys89.fun，把老域名累積的「信任分數」傳遞給主站。 這批是小額試水溫，驗證採購流程與市場行情，下一批才是真正投入的 Tier-1 主力域名。

域名主題DR用途
HipGreenScene.com旅遊主題21Tier-2 連結權重
adviseist.com戶外運動20Tier-2 連結權重
DeckMatt.com多主題24Tier-3 配套

合計 DR 權重 65 分，總購入成本僅 NT$1,197，驗證了「市場有可用的真實老域名」與「我們的採購流程跑得通」。

C. 編輯團隊（5 個獨立人設）

策略目的：Google 2024–2025 演算法連續更新後，「匿名文章」排名大幅下滑，有具體作者署名 + 專業背景的內容才被判定為可信。 5 個人設各有專業領域，讓每篇文章看起來都是由真實的領域專家撰寫，而非一個匿名帳號大量產出，直接提升 E-E-A-T（經驗・專業・權威・可信）評分，進而影響排名。

D. 娛樂城遊戲關鍵字地圖

策略目的：我們主打長尾關鍵字策略。 「娛樂城推薦」這種大詞競爭者有 DR 50+，我們現在搶不過。 但「捕魚機Boss出現時機」、「21點何時加牌」、「539中獎機率計算」這類長尾詞——競爭少、精準度高、搜尋這些詞的人有明確需求，轉換率反而更高。 策略是：先靠 250+ 個長尾詞各帶穩定小流量累積排名信任，等 DR 上去之後再反攻大詞。

⚠️ 競品世足站威脅：

競品也在搶世足流量。wager.tw 把世足內容整合在主站（DR 54 加持，排名更容易），168gambling 有獨立世足站。 我們的優勢是「定位分工最細」——5 站各攻不同搜尋意圖，讓競品無法全面複製；劣勢是 DR 還是 0，需要 PBN 注入權重才能讓這些內容被 Google 看見。

核心問題：

我們在「內容品質」、「結構深度」、「定位分工」已超越競品，但「網域權威分數 DR」差距太大（我們 0 vs 對手 54+），Google 排名演算法把 DR 當第一關，所以我們寫再多內容也排不上前 10。

解法：購入 DR 50+ 高權重老域名做 PBN 連結權重傳遞 → 60 天內 ys89.fun DR 從 0 → 15-20。

A. 2 個高權重老域名採購（已批 NT$10 萬）

剩餘預算 NT$98,803 用於：

  • Tier-1 域名 A（隱匿後盾站主題）：DR 50+，NT$30-50K
  • Tier-1 域名 B（進攻雙 cluster 站主題）：DR 50+，NT$30-50K
  • VPS 主機分散託管：NT$15-25K
  • Spamzilla 域名搜尋工具 1 個月：NT$3K
  • 備用金：NT$5-10K

預期效果：60 天內 ys89.fun DR 從 0 → 15-20，搜尋排名顯著上升，世足期間吃到 5-10 倍流量。

B. PBN v3.2 雙策略建置（已批預算內）

v3.2 放棄單一路線，改為 A/B 雙站策略同時進行，規避 footprint 風險的同時最大化連結效益。

🔒 A 站 — 隱匿後盾

  • 純 HTML 靜態頁（Wayback 老站風格）
  • 不出現在任何 SEO 工具雷達
  • 不直接連結 ys89.fun，透過中間站中轉
  • 主題：世足歷史 / 娛樂城老牌回顧
  • 目的：建立隱形牆，長期穩定輸送權重

⚔️ B 站 — 進攻雙 Cluster

  • WordPress 鏡像站，兩個主題 cluster
  • 戰神賽特 cluster + 捕魚機 cluster
  • 各 10 篇深度文章，直連 ys89.fun 目標頁
  • A/B 站上線時間錯開 5-7 天（防時間 footprint）
  • 目的：短期快速提升母站排名

6 大 Footprint 防護措施：不同主機 IP 段 / 不同域名後綴 / 不同 CF 帳號 / 不同 Whois 資訊 / 不同寫作 voice / 上線時間錯開 5-7 天。
