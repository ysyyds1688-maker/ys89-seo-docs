B. 已採購 PBN 高權重域名（試水溫，僅 NT$1,197）

策略目的：DR 是 Google 排名的第一道門檻。PBN 的做法是買入有真實歷史的老域名，在上面發布相關文章並連結到 ys89.fun，把老域名累積的「信任分數」傳遞給主站。這批是小額試水溫，驗證採購流程與市場行情，下一批才是真正投入的 Tier-1 主力域名。

C. 編輯團隊（5 個獨立人設）

策略目的：Google 2024–2025 演算法連續更新後，「匿名文章」排名大幅下滑，有具體作者署名 + 專業背景的內容才被判定為可信。5 個人設各有專業領域，讓每篇文章看起來都是由真實的領域專家撰寫，直接提升 E-E-A-T 評分進而影響排名。

D. 娛樂城遊戲關鍵字地圖

策略目的：我們主打長尾關鍵字策略。「娛樂城推薦」這種大詞競爭者有 DR 50+，我們現在搶不過。但「捕魚機Boss出現時機」、「21點何時加牌」、「539中獎機率計算」這類長尾詞——競爭少、精準度高、轉換率反而更高。策略是：先靠 250+ 個長尾詞各帶穩定小流量累積排名信任，等 DR 上去後再反攻大詞。

  • Spamzilla 域名搜尋工具 1 個月：NT$3K
  • 備用金：NT$5-10K

預期效果：60 天內 DR 從 0 → 15-20，世足期間吃到 5-10 倍流量。

B. PBN v3.2 雙策略建置

v3.2 改為 A/B 雙站策略同時進行，規避 footprint 風險的同時最大化連結效益。

🔒 A 站 — 隱匿後盾

  • 純 HTML 靜態頁（Wayback 老站風格）
  • 不出現在任何 SEO 工具雷達
  • 不直接連結 ys89.fun，透過中間站中轉
  • 主題：世足歷史 / 娛樂城老牌回顧
  • 目的：長期穩定輸送權重

⚔️ B 站 — 進攻雙 Cluster

  • WordPress 鏡像站，兩個主題 cluster
  • 戰神賽特 cluster + 捕魚機 cluster
  • 各 10 篇深度文章，直連 ys89.fun
  • A/B 站上線時間錯開 5-7 天
  • 目的：短期快速提升母站排名

6 大 Footprint 防護：不同主機 IP 段 / 不同域名後綴 / 不同 CF 帳號 / 不同 Whois / 不同寫作 voice / 上線時間錯開 5-7 天
