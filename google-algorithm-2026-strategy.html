1
Google 搜尋引擎運作 4 層框架 取代傳統 3 步驟

傳統 SEO 教學說「爬取 → 索引 → 排名」，但這個 3 步驟模型只描述 Google 做什麼，不能幫你診斷問題卡在哪。新世代的 4 層框架（akseolabs 主張，與 Google 文件對齊）才是實用 diagnostics 工具。

LAYER 01 · DISCOVERY

發現層

Google 透過 sitemap / 反向連結 / 內部連結找到你的 URL。

⚠️ 卡在此層：你的網站根本沒被 crawler 看到 → 改 sitemap、加外鏈
LAYER 02 · UNDERSTANDING

理解層

解析 HTML 結構、內容語意、Schema 標記、實體（Entity）關係。

⚠️ 卡在此層：被爬到但 Google 不理解你寫什麼 → 改結構化資料、語意豐富度
LAYER 03 · INDEXING

索引層

判斷 canonical、重複內容、品質門檻是否納入索引資料庫。

⚠️ 卡在此層：被理解但沒被索引 → 處理 thin content、duplicate、HCU 風險
LAYER 04 · SERVING（呈現）

呈現層

依查詢意圖排序，以藍色連結 / FAQ / 圖片 / AI Overview 呈現。

⚠️ 卡在此層：被索引但沒排名 / 排名差 → 主題權威、E-E-A-T、CTR 優化
✅ 對 YS89 的啟示

「被爬過 ≠ 被索引 ≠ 有排名 ≠ 有點擊」。母站 ys89.fun 你之前的 35 個空白頁就是卡在 Layer 3 索引層（thin content 過不了品質門檻）→ 我們昨天 TRASH 23 頁 + 補 11 頁就是修這層。剩下的 5 個 fail 主要卡在 Layer 2-4，下一步主要修這幾層。

2024-2026 Google 演算法重大變化時間軸

這些變化決定了我們哪些打法已失效、哪些還能用。每個變化都有具體日期與影響範圍。

2022.08
HCU (Helpful Content Update) 啟動
第一次把「人造內容」「無經驗作者」列為降權因素。為後續所有 affiliate site 命運奠定基調。
2023.09
HCU 大規模更新
大量 affiliate / aggregator / thin content 站流量暴跌 50-90%。「沒有作者署名 + AI 大量產出」直接被砍。
2023.12
⚡ Expired Domain Abuse 偵測上線
跨主題 301 完全失效。博弈舊域名 301 給博弈站、健康舊域名 301 給健康站，這些「主題相關」還有點效果；但「3C 舊域名 301 給博弈站」這種跨主題操作 = 直接降權。
2024.03
Spam Update + Core Update 同步推送
PBN 網路偵測強化，同 GA / 同 hosting / 同 WHOIS 的網路被批量處理。同時 Core Update 增強對「品牌信號弱」的網站打擊。
2024.05
AI Overview（SGE）全面推送（美國）
資訊型查詢（「如何 / 為什麼 / 是什麼」）點擊率下降 20-40%。商業型 / 交易型查詢影響較小。
2024.06
INP 取代 FID 成為 Core Web Vitals 指標
互動性評估從單一反應升級為「整個 session 的回應速度」。對 JS-heavy 網站打擊較大。
2024-2025
Site Reputation Abuse 多次執行
「寄生在大站發 affiliate 文」（Forbes / CNN 等讓 SEO 公司寄生發文）被批量降權。對純白帽影響小，對「買大站發 guest post」打擊大。
2025.Q1-Q3
MUM 系統成熟 + 多模態理解
Google 開始跨語言、跨格式（文字 / 圖 / 影片）理解內容，加強主題權威評估。單篇深度 vs 多篇散亂，前者勝。
2026.Q1（現在）
E-E-A-T 計算更嚴 + AI Overview 台灣全面推送
台灣約 15-20% 查詢出現 AI Overview。無作者署名 / 無更新日期 / 無資料來源 = 直接 deprioritize。
🚨 對 YS89 的啟示

你之前打算「買博弈舊域名 301 給母站」這套，在 2023.12 之後 ROI 直接砍半。我們昨天討論的「分配 5 個老域名」必須改成「非博弈背景 + 主題相關」才安全。

E-E-A-T Trust Evidence Matrix（信任證據矩陣）

akseolabs 強調：「E-E-A-T 不是單一排名分數，而是信任證據框架」。最常見誤區是把它理解成「做了就排名第一」公式 — 實際上應視為「品質訊號的對齊方式」。

維度 什麼意思 YS89 該做的具體動作
Experience
（經驗）		 實測流程、操作截圖、第一手觀察。證明作者真實做過。 每篇出金 / 註冊 / 領體驗金教學都要有截圖、實際時間紀錄、編輯實測案例
Expertise
（專業性）		 清楚定義、判斷條件、風險邊界 + 作者履歷。 5 個編輯筆名（阿凱/小娟/Mark/Jay/阿翔）+ 每個有專業領域 bio
Authoritativeness
（權威性）		 被官方來源 / 產業共識 / 內部主題網絡引用。 內部 Hub & Spoke 內容架構、外鏈到 PTT/Dcard 真實討論
Trustworthiness
（可信度）		 來源標註、更新日期、商業揭露、安全資訊。 編輯方針頁、利益揭露、最後更新日期、HTTPS、隱私政策（都已有）

akseolabs 提的「AK Trust Evidence Matrix」

每個主張都要對應到 頁面證據（讀者看得到）+ 實體證據（作者背景 / 網站信譽）。不能只說「我們很專業」，要說明「判斷條件是什麼、適用情境是什麼」。

💡 AI 搜尋時代的關鍵變化

信任證據要 「可抽取、可歸因、可追溯」 才能被 AI Overview 正確引用。代表 E-E-A-T 訊號不能只藏在「關於」頁，應分散在每個重要段落。我們的 5 編輯人設 + 文末署名標準格式就是在做這件事。

YMYL 風險差異化

娛樂城屬於 YMYL (Your Money Your Life) 高風險類別 — Google 對這類內容信任要求更嚴。需要：

  • 明確的風險邊界聲明（每篇都要有「投注風險自負」）
  • 引用官方來源（平台公告 / 公開玩家投訴）
  • 更新日期不能超過 6 個月
  • 不能有任何「保證獲利 / 穩賺 / 必勝」字眼
4
AI Overview / Query Fan-Out / GEO 優化

2025-2026 Google 流量結構已被 AI Overview 重塑。akseolabs 點出最關鍵的概念：Query Fan-Out。

什麼是 Query Fan-Out

Google 收到用戶 query 後，會「把它分解成多個子查詢」，分別在內部搜尋，最後組合答案。在最多子查詢中反覆出現的頁面，被引用機率最高。

例如用戶搜「2026 世足如何投注」，Google 內部會 fan out 成：

  • 「世足讓球盤是什麼」
  • 「2026 世足賠率」
  • 「世足投注新手」
  • 「合法世足投注平台」
  • 「世足走地投注」

你的內容必須同時在這 5 個子查詢都有出現，才會被 AI Overview 選為引用來源。

5 大 AI Overview 優化策略（akseolabs）

策略具體做法效果
自給自足答案段落 每章節首段「脫離上下文獨立回答問題」，134-167 字之間（利用 Passage Ranking） 提升被 AI Overview 選中機率
實體密度布局 頁面包含 15+ 個語意相關實體（球隊、球員、賽事、賠率類型等） 引用機率 +4.8x
多模態內容 文字 + 圖片 + 結構化資料 引用率 +156%；加影片 +317%
跨主題覆蓋 互連的語意 cluster，讓 Query Fan-Out「多次挑中你」 比超長文有效
E-E-A-T 真實信號 具名作者、外部媒體提及、引用學術資料 真實信號 > 格式技巧

跟傳統 SEO 的最大差異

傳統 SEO 追求整篇文章排名；AI Overview 評估的是段落層級語意完整度。兩者不衝突但粒度不同。

📌 對 YS89 具體執行

1. 每篇文章每個 H2 標題之下，第一段都要 134-167 字的「獨立答案」（不依賴前後文就能讀懂）
2. 每個世足文章要包含 15+ 個實體（球隊名、球員名、賽事名、賠率類型、平台名）
3. 用 FAQ Schema + Article Schema 包裝
4. ys89.fun 的 5 編輯人設 + 文末署名就是 E-E-A-T 信號落地

Core Web Vitals + INP 新指標

2024.06 起 Google 用 INP (Interaction to Next Paint) 取代 FID 作為互動性指標。這是 Core Web Vitals 重大更新。

指標意思良好需改善不佳
LCP 最大內容繪製（首頁主圖載入完成） ≤ 2.5s 2.5-4s > 4s
INP 新 互動到下次繪製（點擊/捲動反應） ≤ 200ms 200-500ms > 500ms
CLS 累積版面位移（畫面跳動程度） ≤ 0.1 0.1-0.25 > 0.25
✅ 對 YS89 的啟示

我們昨天壓縮 5 張首頁圖（11.4MB → 3.6MB）+ 換 WebP（→ 0.98MB）就是修 LCP。INP 是 JS-heavy 才有問題，ys89.fun WordPress 大部分頁面 INP 應該 OK。CLS 我們的 Hero 圖有設 alt 但要確認有設 width/height 屬性避免版面跳動。

主題權威（Topical Authority）vs 關鍵字堆砌

akseolabs 的核心主張：「SEO 關鍵字研究的核心，不是堆砌搜尋量，而是建立 Topical Authority」。

Hub & Spoke 內容架構

用「支柱頁面（Pillar Page，主題 hub）+ 叢集文章（Cluster Articles，輻射 spokes）」建構主題網絡：

【支柱頁】娛樂城出金完整指南（hub）
├─ 【叢集】USDT 出金教學
├─ 【叢集】銀行轉帳出金
├─ 【叢集】出金被拒怎麼辦
├─ 【叢集】出金速度比較 2026
├─ 【叢集】各家平台出金實測
└─ 【叢集】超商代碼出金教學
各 spoke 互連 + 全部連回 hub

為什麼這比單關鍵字優化強

  • Query Fan-Out 機率提升：每個 spoke 都可能被 AI Overview 引用
  • 主題權威累積：Google 看到「同一站對該主題有完整覆蓋」
  • 內部 PageRank 流動：spoke 互連把權重集中到 hub
  • 讀者體驗：找到一篇就能跳到全套相關資料
