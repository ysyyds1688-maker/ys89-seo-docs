⚡ 極速 SOP（推薦流程）

🎯 核心觀念：DR 是 Ahrefs 已經幫你做的「總體判斷」

Ahrefs 的 DR (Domain Rating) 是綜合了「連結數量、來源網域品質、流量、權威性」算出來的單一分數。換句話說，Ahrefs 演算法已經看完所有訊號才給你 DR 數字。

所以你要做的，不是手動分析 BL / LW / dofollow → 而是用 DR 當第一道篩，DR < 10 直接 pass，根本不用花時間看其他數字。

📋 兩階段流程

1第一階段：純看 Ahrefs（每個 30 秒，30 個共 15 分鐘）
  • 把 30 個域名分批貼進 Ahrefs Backlink Checker
  • 每個只記 3 個數字：DR / RD（Linking websites）/ LW dofollow%
  • 按照下方「秒判表」標記 ✅ / ⚠️ / ❌
  • 結束後通常會剩 5-10 個 ✅ 候選
2第二階段：只對 ✅ 候選做 Wayback + Google（每個 5 分鐘，10 個共 50 分鐘）
  • 用後面教的「3 點抽樣法」+「Summary 速判法」看歷史
  • 確認後決定最終購買清單

🚦 Ahrefs 秒判表（最重要）

情境動作原因
DR < 10❌ 直接淘汰，不用看其他數字Ahrefs 已經判定連結品質低
DR 10-14 + LW dofollow 30-60%⚠️ 候補，回 Wayback邊緣可救
DR ≥ 15 + LW dofollow 30-60%✅ 進第二輪連結結構健康
DR ≥ 15 但 LW dofollow > 80%❌ 淘汰（PBN 痕跡）過度集中 dofollow = 鏈接農場
DR ≥ 15 但 LW dofollow < 20%❌ 淘汰（假連結）幾乎全 nofollow = 沒實質權重

🤔 為什麼有兩個 dofollow%？怎麼讀？

Ahrefs 結果頁會顯示兩個百分比，意思不同：

數字意思
BL XXk (98% dofollow)所有反向連結裡，98% 是 dofollow 類型
LW 115 (23% dofollow)115 個來源網域裡，只有 23% 的網域有 dofollow 連結過來（約 26 個網域）
典型 spam 訊號：BL dofollow 高 + LW dofollow 低（例如 98% / 23%）
解讀：少數網站灌水大量 dofollow 連結（如 footer/sidebar/comment spam）。
算給你看：26 個 dofollow 來源網域 × 平均 140 條連結 ≈ 3,600 條 dofollow BL = 鏈接農場特徵。
健康訊號：BL 跟 LW 的 dofollow% 接近（例如 BL 60% / LW 55%）
解讀：連結分布平均，每個來源網域只丟少量連結 = 自然引用模式。

⚠️ 唯一例外：超老域名（ABY < 2008）

如果 ExpiredDomains 表上 ABY < 2008（17 年以上老域名），就算 DR 只有 8-12 也值得回 Wayback 看一眼，因為老域名歷史品牌價值 > Ahrefs 數字。但這種域名通常是「整批 spam 倒貼」狀態，買回來要花時間 disavow 清連結。

ABY 2010-2015 的「中老域名」完全照 DR 標準篩，不破例。

🟢 第一關：Wayback Machine 歷史回溯（僅對 Ahrefs ✅ 候選做）

🌐 工具網址

https://web.archive.org/web/*/[你的域名]

例：https://web.archive.org/web/*/gamezforums.com

🚀 30 秒速判法：直接點頁面頂端的「Summary」按鈕
Wayback 頁面頂端有 6 個分頁：Calendar / Collections / Changes / Summary / Site Map / URLs
點「Summary」會看到該域名歷年的 Content type / MIME types / Top hostnames 統計摘要 → 一眼看出是不是賭博站（casino / porn / pharma 等字眼會出現在 hostname 列表）
Summary 乾淨 → 才進入下方 3 點抽樣；Summary 髒 → 直接淘汰，省 5 分鐘

🎯 3 點抽樣法則（只看 3 個快照，不要每個都看）

過期域名最常見的污染模式：

2002-2010：正常英文部落格 ✓
2011-2018：被駭客接管 → 改成賭博站 ❌（最高條通常在這裡）
2019-2024：站主放棄，停止更新
2025：域名到期釋出 → 你買到的是這個版本

如果只看「早期 + 晚期」會誤判為「以前正常、後來放著」→ 中期被駭的黑歷史會漏掉。所以必須早/中/晚各看 1 個。

抽樣點為什麼選怎麼選年份
早期看原始用途頁面頂端時間軸最左邊有黑條的年份
中期看有沒有被駭/被改用途（最關鍵）時間軸最高的 1-2 條所在的年份
晚期看到期前最後狀態時間軸最右邊有黑條的年份（通常 2023-2024）
💡 為什麼「最高條」一定要看？
最高條 = 那年快照最多 = 那年被爬最頻繁 = 通常是「站爆紅」或「站被駭」的年份。
被駭/改用途的站通常會被 spam bot 大量爬取，所以最高條年份是污染最可能發生的時間點，必看。

📋 完整操作步驟（5 步）

📋 操作步驟（5 步）

1進入 Wayback 頁面後，先看「最上方說明」
  • Saved X times between [首次年] and [最後年]
  • 記下 3 個數字：首次年、最後年、X (快照數)
✅ 好訊號：首次年 < 2015，快照數 > 30，最後年 ≥ 2024（代表一直被使用）
❌ 壞訊號：首次年 ≥ 2020（不是真老域名）或 快照數 < 10（沒被認真經營過）
2看「年份長條圖」（黑色直條）找活躍期
  • 長條越高 = 那年快照越多
  • 挑 3 個年份代表期抽查：早期（2010 前）/ 中期（2015-2018）/ 晚期（2022-2024）
  • 為什麼分 3 期？因為**過期域名最常見的污染是「中期被駭」**——本來是正常公司站，2017 年被改成賭博/藥品站。
3點選某個年份 → 進入該年的月曆視圖
  • 把上方的時間滑桿往右拉，或直接點時間軸上的年份
  • 看到該年的 12 個月份月曆
4點月曆上的「藍/綠圓點」進入真實快照
  • 🔵 藍點 = 普通快照
  • 🟢 綠點 = HTTP 200 成功快照
  • 隨便點 1 個（建議點該月最大的點）
  • 網頁會載入「該天該網站的長相」
5判讀網站內容 → 填表
填入欄位要看什麼範例
Wayback_主題網站在賣什麼/做什麼「遊戲論壇」「法國輪胎店」「個人部落格」
Wayback_語言主要語言「英文」「法文」「簡中」「繁中」「土耳其文」「越南文」
Wayback_有無賭博成人藥品有任一就填 YY / N

🚦 紅燈黑名單（任一出現就 ❌ 直接淘汰）

  • 🎰 賭場 / 老虎機 / 百家樂 / casino / poker / bet / slot 字樣
  • 🔞 成人/色情圖片 / 裸露 / xxx 字樣
  • 👜 仿冒精品（fake Nike / Gucci outlet / cheap jerseys）
  • 💊 藥品（cialis / viagra / pharmacy / 壯陽）
  • 📱 中國簡體中文非正規站（高機率被牆，Google 已標記）
  • 🏦 加密貨幣詐騙 / ICO / forex 套利
  • 📚 文憑造假（diploma / certificate / fake degree）

🟢 綠燈白名單（看到任一就加分）

  • 🏢 小公司形象站（建築 / 顧問 / 法律事務所）
  • 📝 個人部落格 / 旅遊網誌 / 食譜站
  • 🎮 遊戲論壇 / 玩家社群（對體育站超適合）
  • 🏃 運動俱樂部 / 健身房 / 訓練營
  • 📰 地方新聞站 / 地區資訊網
  • 🛒 已停業的電商（家具 / 服飾 / 工具）
  • 🅿️ Domain Parking 頁（從未被使用，最乾淨）

🟡 第二關：Ahrefs 反向連結檢查

🌐 工具網址

https://ahrefs.com/backlink-checker

注意：免費版每日有額度上限（約 5-10 次/天/IP），用完就要等隔天。建議優先查 Wayback 過關的候選。

📋 操作步驟

1進入 Ahrefs backlink checker 網頁
2輸入域名（不用加 https://），按 Check backlinks
3等 5-10 秒，會跳出彈窗顯示 4 個數字

📊 你會看到的 4 個數字 → 對應填入哪欄

Ahrefs 顯示填入欄位合格標準
Domain Rating (DR)Ahrefs_DR≥15 ✓ / 10-14 ⚠️ / <10 ❌
BacklinksAhrefs_BL總數參考用（多不一定好）
Linking websitesAhrefs_RD連結網域數≥30 ✓ / 10-29 ⚠️ / <10 ❌
% dofollowAhrefs_dofollow百分比30-80% ✓ / >90% ❌（PBN 訊號）
⚠️ 關鍵警訊：dofollow 比例 > 90%
自然網站 dofollow 通常 30-60%（混合社群、Wikipedia 等多種 nofollow）。
98% dofollow ≈ 被 PBN/鏈接農場做過 SEO，Google 早已內部標記 → ❌ 直接淘汰

🔵 第三關：Google 搜尋殘留

📋 兩個查詢

1查殘留索引
site:[域名]

例：site:gamezforums.com

  • Google 結果頁會寫「約 X 項結果」
  • 填入 Google_site殘留頁數
  • >100 頁 = 很好（Google 還記得）
  • <10 頁 = 已被淡忘（也 OK，反正要重建內容）
2查黑歷史
"[域名]"（含引號）

例："gamezforums.com"

  • 看有沒有負面新聞：詐騙報導 / 被列黑名單 / spam 抱怨
  • 填入 Google_黑歷史新聞：Y（有）/ N（無）

🏆 最終判定邏輯

等級條件動作
✅ 必買 Wayback 綠燈 + DR ≥ 20 + RD ≥ 50 + dofollow 30-70% + 無黑歷史 立即出價（NT$ 5,000-15,000）
✅ 可買 Wayback 綠燈 + DR ≥ 15 + RD ≥ 30 + dofollow ≤ 80% 可出價（NT$ 2,000-8,000）
⚠️ 觀望 條件部分達標，例如 DR 12 但其他都好 低價搶（NT$ < 2,000）
❌ 放棄 任一紅燈（賭博/成人歷史/dofollow>90%/DR<10） 不買
