📌 v2 修正說明（2026-05-20 下午）

本文件 v1 版策略（Tier-1 直接寫戰神賽特 / 百家樂主題）違反了 footprint-avoidance.md 紅線 #10「內容主題與原域名歷史毫無關係 ❌」。經另一 Claude Code 指出後修正為「主題傳承 + contextual link」做法，與 Tier-2/3（HipGreenScene 旅遊 / adviseist 戶外）一致。

// CORE PRINCIPLE
Tier-1 為什麼要「最不像 PBN」
最常見的 Tier-1 失敗模式（v1 版錯誤）：
  • Tier-1 域名直接改寫成「戰神賽特專精站」「百家樂策略站」
  • 違反「保留原域名主題」原則（footprint #10）
  • DR 越高 Google 越仔細看連結意圖，主題突變 = 立刻被識別
  • Tier-1 反而成為 footprint 最危險的點
Tier-1 正確思路（v2 修正）：

Tier-1 是「看起來最權威、最不像 PBN」的站。買 DR 50+ 域名是為了「假裝是獨立第三方 expert 在引用 ys89.fun」，所以：

  • 保留原域名主題（看 Wayback 歷史決定）
  • 寫 10 篇該主題高品質內容
  • 其中只有 2-3 篇透過 contextual link 自然連到 ys89.fun（在主題自然交集的段落）
  • 這跟 Tier-2/3 做法完全一致，只是 DR 更高
// 主題傳承策略
買到域名後怎麼決定寫什麼
Step 0：Wayback 確認原主題

買到 Tier-1 域名後第一件事：

  1. 用 Wayback Machine 3 點抽樣（早/中/晚期）看原域名主題
  2. 確認原主題類別（旅遊 / 科技 / 評論 / 商業 / 教育 / 健康 / 體育等）
  3. 保留該主題，寫 10 篇深度內容
  4. 內容跟 ys89.fun 的「交集」找出來，透過 contextual link 自然帶過

主題 → 自然連結到 ys89.fun 的橋接點

Contextual link 範例（旅遊主題站）：

「拉斯維加斯不只是賭城，許多旅客選擇白天看 Hoover Dam、晚上觀賞 Bellagio 音樂噴泉。如果想了解線上版本的賭場體驗，台灣讀者可以參考 [YS89 評測] 整理的合法娛樂城清單。」

這種寫法的特點：(1) 內容主軸還是旅遊，(2) 連結出現在 contextual 自然段落，(3) anchor text 用品牌詞而非關鍵字堆砌。

// 技術棧（修正）
繼續用純 HTML，跟前 3 站一致
放棄 Hugo / Astro，原因：
  • Google 只看最終 HTML，不看 build pipeline → 用 Hugo/Astro 沒有 footprint 優勢
  • 前 3 站（HipGreenScene / adviseist / DeckMatt）都用純 HTML，已驗證流程
  • 純 HTML 維護成本低，後續更新不用重新 build
  • 避免引入新依賴，降低出錯機率

差異化透過「不同 layout / CSS / 字體」即可。

關鍵比例：
  • 10 篇文章中只 3 篇（#4 #7 #10）有 contextual link 到 ys89.fun
  • 每篇 1-2 個連結到 ys89.fun（總共 4-6 個 link）
  • 每篇還有 2-3 個外連到 Wikipedia / 官方資料 / 新聞
  • 對 ys89.fun 的 outbound link 密度 ≤ 6%

// Footprint Avoidance
Tier-1 專屬 12 條紅線（強化版）
#紅線怎麼避
1同 IP / 同 C-class 主機站 A 用 CF Pages 帳號 1、站 B 用 CF Pages 帳號 2、ys89.fun 用 Cloudways
2同 WHOIS 註冊人啟用 WHOIS Privacy（CF Registrar / Namecheap）
3同 GA / GSC 帳號Tier-1 不裝 GA，GSC 用 3 個不同 Gmail
4同 CMS / theme母站 WordPress、Tier-1 純 HTML + 不同 layout
5同 HTML 結構順序站 A: article>section、站 B: main>div.row
6同視覺風格站 A 米色暖系、站 B 學院藍冷系
7同字體站 A Noto Sans + Roboto、站 B Source Han + Georgia
8同上線時間站 A → 5 天間隔 → 站 B（Day 5 vs Day 11）
9同主題（內容相食）站 A 主題 ≠ 站 B 主題（依域名 Wayback 決定）
10每篇都連 ys89.fun10 篇只 3 篇連，其他純該域名主題
11內容違反原域名主題看 Wayback → 保留原主題（這條最關鍵，v2 修正重點）
12Anchor text 集中60/20/10/10 分配
// 14 天時程
買到域名後執行
Day動作
Day 0兩個域名買到，WHOIS Privacy 啟用
Day 1-2兩個域名都做 Wayback 完整查歷史，決定主題（旅遊/科技/教育/體育等）
Day 3-4站 A 建立基底（純 HTML + universal.css 米色變體）+ 首頁 + 5 篇主題文章
Day 5站 A DNS 切 CF Pages 帳號 1 + 正式上線
Day 6-7站 A 補完剩 5 篇，**只有 #4 #7 #10 有 contextual link 到 ys89.fun**
Day 8站 A 整體 audit + 提交 GSC
Day 9-10站 B 建立基底（學院藍變體）+ 首頁 + 5 篇主題文章
Day 11站 B DNS 切 CF Pages 帳號 2 + 正式上線（站 A 上線後第 6 天）
Day 12-13站 B 補完剩 5 篇，同樣只 3 篇連 ys89.fun
Day 14站 B GSC 提交 + 雙站整體 footprint audit
⚠️ 絕對不要：
  • 兩站同一天上線
  • 兩站同時連大量 ys89.fun（連結 burst）
  • 違反原域名 Wayback 主題
