⚠️ 高風險警告

用同 WordPress + 同 theme = footprint 風險高。必須做以下 6 條防護才能執行：

#防護項目具體做法
1Theme 重命名ys-entertainment-theme → zeus-baccarat-theme（含 function namespace）
2獨立 admin email新 Gmail（zeus-bac-admin@gmail）+ 不同密碼
3SEO plugin 換Rank Math → 改用 Yoast SEO
4不同 hosting IP新 Cloudways 帳號 + 不同 region server
5不裝 GA / 獨立 GSC不要裝 Google Analytics；用獨立 Gmail 註冊 GSC
6wp-content 結構微調image folder rename、CSS path 微改、移除明顯 ys89 特徵
