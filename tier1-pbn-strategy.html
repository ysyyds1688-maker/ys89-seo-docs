⚠️ 高風險警告

用同 WordPress + 同 theme = footprint 風險高。必須做以下 6 條防護才能執行：

#防護項目具體做法
1Theme 重命名ys-entertainment-theme → zeus-baccarat-theme（含 function namespace）
2獨立 admin email新 Gmail（zeus-bac-admin@gmail）+ 不同密碼
3SEO plugin 換Rank Math → 改用 Yoast SEO
4不同 hosting IP新 Cloudways 帳號 + 不同 region server
5不裝 GA / 獨立 GSC不要裝 Google Analytics；用獨立 Gmail 註冊 GSC
6wp-content 結構微調image folder rename、CSS path 微改、移除明顯 ys89 特徵

// 60 天驗收
A vs B 對比表（業主用）
指標A 站目標B 站目標對比意義
ys89.fun 收到的連結數3 條5 條B 帶來更多 link juice
該站 DR 上升0 → 5-100 → 10-20B 比 A 快 1.5-2 倍 = 進攻策略有效
該站索引頁數10/1011/11哪個 deindex = footprint 警訊
該站自然流量月增500+1500+B 流量 3 倍 = 進攻吃到流量
ys89.fun DR 受益+3-5+8-12B 對母站貢獻更大
Google penalty 風險低中B 萬一被罰 = 損失 NT$40K，A 仍在
業主看 60 天 KPI 後可決定：
  • B 達標 + A 達標 → 兩條路都有效 → 加碼買第 2 批雙站
  • B 達標 + A 普通 → 進攻策略更好 → 下次只買進攻型
  • B 不達 + A 達標 → 隱匿策略更穩 → 下次只買隱匿型
  • B 被罰 + A 達標 → 慶幸有 A 後盾 → footprint 防護加強
  • 都不達標 → 暫停 PBN 投資，剩餘預算轉投廣告
