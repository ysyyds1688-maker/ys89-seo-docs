## 五、必修的 SEO Bug

### Bug 1：robots.txt 被 Rank Math 擋到
Rank Math 的 robots.txt 編輯器改不了實體檔案。用 SSH 直接覆蓋：
```bash
cat > /path/to/public_html/robots.txt << 'EOF'
# 貼上上面的 robots.txt 內容
EOF
```

### Bug 2：作者頁面 500 錯誤
Really Simple Security 的 `wp_die()` 會造成 500。
在 `wp-content/mu-plugins/` 新增 `fix-author-enum.php`：
```php
<?php
add_action('init', function() {
    if (!is_user_logged_in() && isset($_REQUEST['author'])) {
        if (preg_match('/\d/', $_REQUEST['author']) > 0) {
            remove_action('init', 'rsssl_check_user_enumeration');
            wp_redirect(home_url('/'), 301);
            exit;
        }
    }
}, 1);
```

### Bug 3：Global Meta 預設 noindex
Rank Math 安裝後 Global Meta 可能是 noindex。
`Titles & Meta → Global Meta → Robots Meta → 改為 index, follow`

## 九、快取清除順序（每次改完都要做）

```bash
# 1. 清 WP 物件快取
wp cache flush

# 2. 清 WP Fastest Cache 頁面快取
wp eval 'if(class_exists("WpFastestCache")){(new WpFastestCache())->deleteCache(true); echo "WFC cleared";}'

# 3. 清 Varnish（Breeze）快取 - 最重要！
curl -X PURGE https://你的網域/
curl -X PURGE https://你的網域/*

# 4. 清 OPcache（透過 HTTP）
# 在 public_html 放一個臨時 PHP 檔：
echo '<?php opcache_reset(); echo "OK";' > public_html/clear-op.php
curl https://你的網域/clear-op.php
rm public_html/clear-op.php
```
