## 四、各站互連邏輯

```
站2（排行）──────┐
站3（攻略）──────┤──→ ys89.fun（主論壇）──→ LINE ──→ ys89.bet
站4（警示）──────┘         ↑
                           │
                    各站互相引用為「延伸閱讀」
```

**互連規則：**
- 每篇文章底部加「延伸閱讀」連到其他站相關文章
- 不要同一 IP 大量互連（避免 Google 判斷為 link farm）
- 每個站要有獨立的寫作風格、目標讀者定位

## 五、域名與主機策略

### 建議
- 每個站用不同域名（.tw 優先，台灣市場信任度高）
- 主機：Cloudways 同一台 VPS 可以開多個 App（節省費用）
- 每個 App 用不同的 Cloudflare 帳號或至少不同 Zone（降低關聯性）

### 成本估算（每月）
| 項目 | 費用 |
|------|------|
| Cloudways VPS（現有）| 已付 |
| 新增 3 個 App（同台 VPS）| 幾乎免費 |
| 域名 × 3（.tw）| ~NT$1,500/年 |
| Cloudflare（免費版）| 免費 |

## 六、內容生產策略

### 短期（第1-4週）：手動 + Claude 輔助
- 每站先建立 10-20 篇核心文章
- 使用 Claude（對話）逐篇生成，直接 WP-CLI 發布
- 確保每篇有正確 Focus Keyword + Meta Description

### 中期（第5週+）：半自動化
- 爬蟲抓競爭對手文章 → Claude API 改寫 → WP-CLI 自動發布
- 參考：`自動發文腳本_規格書.md`
- 每站每天 1-3 篇，靠 cron job 定時執行

### 長期：UGC + 社群
- ys89.fun 的 bbPress 論壇引導真實玩家留言
- UGC 內容 Google 最愛，E-E-A-T 分數提升
- 玩家討論本身就是新內容，降低人工成本
