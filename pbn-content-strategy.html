🕸️ YS89 PBN 內容策略

核心問題：買了高權重域名之後，要寫什麼內容？能不能複製 ys89.fun 的風格？
核心答案：不能。PBN 域名必須「看起來像獨立的真實網站」，否則 Google 馬上識破。
製作：2026-05-20 | 阿翔（Sean）

⚠️ 為什麼不能複製 ys89.fun 的策略到 PBN？

Google 偵測 PBN 的 8 大訊號（任一中招就被識破）：
  1. 內容主題集中：所有 PBN 都寫娛樂城 = 一望即知
  2. 外連模式單一：所有 PBN 都連 ys89.fun = footprint 明顯
  3. 同 IP / C-class：主機集中
  4. 同 WHOIS：註冊人資訊重複
  5. 同 footer / theme：模板抄一樣
  6. 同 Google Analytics ID：追蹤碼洩底
  7. Anchor text 同質：100% 都用「夜色娛樂城」
  8. 連結密度過高：每篇文都連 ys89.fun
結論：PBN 不是「縮小版 ys89.fun」，是「外型完全不同的旁支系統」，透過自然連結傳遞權重。

🎯 3 層 PBN 架構（不同 DR 不同玩法）

層級DR 範圍數量定位連結策略
Tier-1 旗艦 DR 40+ 1-2 個 真實感最強的權威站 301 跳轉 OR 自然 contextual link 到 ys89.fun
Tier-2 主力 DR 20-40 5-8 個 同主題權威站 每篇 1-2 個內鏈到 ys89.fun（品牌錨）
Tier-3 配套 DR 10-20 5-10 個 支援 Tier-2 的小站 Tier-3 → Tier-2（不直連 ys89.fun，避免明顯）
權重流動圖：
Tier-3 (支援站) → Tier-2 (主力站) → ys89.fun (受益站)

Tier-3 不直接連 ys89.fun，是因為 Tier-3 通常品質較差。讓它們先把權重灌給 Tier-2，再由 Tier-2 「過濾」乾淨後傳給 ys89.fun。
🥇 Tier-1 旗艦 DR 40+

核心策略

用「真實內容創作」偽裝成獨立網站，Google 看不出是 PBN。

內容規格

  • 篇數：每站 20-30 篇深度文章（每篇 1,500-3,000 字）
  • 更新頻率：每月新增 2-3 篇，持續 6-12 個月
  • 原創度：100% 原創（不能 AI 完全生成，要人工潤稿）
  • 內鏈密度：每篇文章 5-10 個內部連結（同站內互鏈）
  • 外連 ys89.fun：每篇 0-1 個（部分文章不連，看起來自然）
  • 非 ys89 外連：每篇 2-3 個（連 Wikipedia / 官方資料 / 新聞）

主機/設定隔離（嚴格）

  • 獨立 VPS（不同 IP，不同國家更好）
  • 獨立 CF 帳號（不同 email）
  • 獨立 GA4（或乾脆不裝 Analytics）
  • WHOIS 用 CF Registrar 隱私保護
  • WordPress 用不同主題（不能跟 ys89.fun 同主題）
  • 不同 admin email + 不同 GSC 帳號

301 跳轉決策

方案用途風險
方案 A：保留站點 + 內含連結長期 PBN 經營低（要持續寫內容）
方案 B：整域 301 跳 ys89.fun快速權重注入中（Google 會檢視 301 來源是否合理）
方案 C：301 部分頁面混合策略低

建議：方案 A（長期投資）。301 整域容易被 Google 識破，特別是過期域名重新註冊立即 301。

🥈 Tier-2 主力 DR 20-40

核心策略

建「同主題權威站」，內容跟域名歷史主題盡量保持一致（傳遞 topical relevance），定期注入連結到 ys89.fun。

內容規格

  • 篇數：每站 10-15 篇文章（每篇 1,000-2,000 字）
  • 更新頻率：每月新增 1-2 篇
  • 原創度：80%+ 原創，可用 AI 輔助但要重寫
  • 內鏈密度：每篇 3-5 個內部連結
  • 外連 ys89.fun：每篇 1-2 個（contextual，自然出現）
  • 非 ys89 外連：每篇 1-2 個（其他權威站）

Anchor Text 分配（最重要）

品牌錨
60%
裸 URL
20%

10%

Anchor Text 範例

品牌錨 (60%): "ys89"、"夜色娛樂城"、"YS89 評測"、"ys89.fun" 裸 URL (20%): "https://ys89.fun"、"ys89.fun/casino-account-frozen-2026/" 通用詞 (10%): "點此查看"、"完整指南"、"閱讀更多"、"詳細說明" 關鍵字 (10%): "百家樂評測"、"出金教學"、"警示帳戶解除"
絕對不要：所有連結都用「夜色娛樂城」這同一個錨文字。100% 同質 = footprint 明顯。

主機/設定隔離（中度）

  • 不同 VPS 共用 1-2 個 IP（Tier-2 不需要每個都獨立 IP）
  • 同一個 CF 帳號可以放 3-5 個 Tier-2 站（不要超過 5）
  • WHOIS 用 CF Registrar 隱私保護
  • WordPress 主題每 2-3 個站換一個
🥉 Tier-3 配套 DR 10-20

核心策略

輕量內容，主要任務是「灌權重給 Tier-2」。不直接連 ys89.fun。

內容規格

  • 篇數：每站 5-10 篇基礎文章（每篇 600-1,200 字）
  • 更新頻率：每 2-3 個月更新 1 篇即可
  • 原創度：可用 AI 生成大量內容，輕度潤稿
  • 連結對象：Tier-2 站點 + 中性外部資源
  • 連結 ys89.fun：禁止直連

主機/設定（寬鬆）

  • 可以集中放 1 個 VPS（同 IP 沒關係，因為 DR 低 Google 比較不關注）
  • 共用 CF 帳號可以
  • 內容可以模板化
Tier-3 的真正用途：不是直接給 ys89.fun 加分，而是讓 Tier-2 主力站「看起來有人引用它」。Google 看到 Tier-2 有反向連結 → 給 Tier-2 加 DR → Tier-2 連 ys89.fun → ys89.fun 受益。

🚨 避雷紅線（任一中招 = PBN 暴露）

絕對禁止：
  • 所有 PBN 都連到 ys89.fun 同一頁面
  • 所有 anchor text 都是「夜色娛樂城」
  • 所有 PBN 共用 Google Analytics ID
  • 所有 PBN 共用 footer 簽名或聯絡 email
  • 所有 PBN 同一個 IP 主機
  • 剛買域名立刻 301 整域到 ys89.fun（需先養 1-3 個月再 301）
  • 內容 100% AI 生成（要人工潤稿）
  • 連結密度過高（每篇文章超過 3 個 ys89.fun 連結）
  • 所有 PBN 同一天大量發文（要分散）
  • PBN 之間明顯互連結（要透過中間站）
必須做：
  • 每個 PBN 主題與原域名歷史保持一致或相關（保留 topical authority）
  • Anchor text 分散（品牌錨 60% / 裸 URL 20% / 通用 10% / 關鍵字 10%）
  • 不同 PBN 用不同 WordPress 主題
  • 外連除了 ys89.fun，每篇也連 2-3 個權威站（Wikipedia / 新聞）
  • 定期更新（每月至少 1 次）
  • 追蹤 GSC 確認沒被人工懲罰
