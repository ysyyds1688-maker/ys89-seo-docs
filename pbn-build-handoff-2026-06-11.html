🏗️ PBN 建站交接文件

目標:新建 PBN 站,透過 two-hop 把權重導向 ys89.fun ・ 2026-06-11 ・ 依 YS89 PBN 網絡戰略擬定
⚠️ 給協助者的第一鐵則:這是把「乾淨權重」導給主站,不是灌垃圾連結。
我們剛因為被灌入 175 個垃圾連結(seoexpress.store 那種賣連結網絡)導致 DR 從假性 30 掉到真實 13。絕對不要碰任何「買連結 / 老域名外鏈套餐 / 自動外鏈工具」——那正是害我們掉分的東西。PBN 的價值在「真實、隔離、自然」,不在數量。

① 核心原則:PBN 直連 ys89.fun(加速版)

新 PBN 直接連 ys89.fun,不繞衛星,讓權重最快導到母站:

新 PBN ➜ ys89.fun(直連)

  • 為什麼直連:two-hop 經衛星會衰減、慢;直連權重最快到母站(母站目前 DR13 急需拉)
  • 連結目標分配:ys89.fun 首頁 20% / 分類頁(/casino-ranking、/games 等)40% / 深度 pillar 文 40%(出金/百家樂/詐騙懶人包那幾篇)
  • 為什麼多連分類+文章頁:全連首頁最假;連內頁更自然,也順便拉內頁排名
⚠️ 直連=快但 footprint 風險高,務必靠這三條防線守住(否則重蹈 DR13):
1. PBN 要乾淨 — 真實 niche、養站期、正規內容(髒站直連母站 = 把母站一起拖下水)
2. 錨文字嚴格分散 — 衛星站現在就是錨文字太集中「夜色娛樂城」被判 SPAM,直連母站更要照 ④ 的比例,精確競爭詞 ≤20%
3. 速度要慢 — 每站每月最多 1-2 條連母站,全網一個月別超過 5-6 條新連;Google 看 velocity,暴增=紅旗

② Footprint 隔離(最重要,出錯全網連坐)

項目規則
主機 IP每站 IP 完全分離,至少跨 3 家供應商(Cloudways / Hostinger / Vultr 或 Linode);避開 SGP1 + ys89.tw 同機房
網域註冊商新站換不同註冊商(Namecheap / Porkbun / Cloudflare Registrar);立刻開 WHOIS Privacy;付款用虛擬卡避免 pattern
GitHub / CF 帳號每站專屬帳號 + 專屬 email;禁從主帳 ysyyds1688-maker 操作;同帳號共用的站 push 要間隔 3-5 天
GSC 驗證國家每站固定用「當初驗證的國家」VPN(deckmatt=加拿大 / adviseist=美國 / hipgreenscene=加拿大 / bolalive77=馬來西亞);母站 ys89.fun 永遠用澳洲
Commit / 內容口吻用該站人設口吻;不同站 commit message 不要同句型;robots.txt 封鎖 AI 爬蟲的策略各站要略不同(別全一致)
社群訊號PBN 絕對不連 12 個 ys89 品牌 IG;要社群訊號開新假帳號

③ 內容規範(連結之前先養站)

  1. 養站期:放連結前先發 10-15 篇純 niche 內容(完全正規,跟博弈無關),養 4-6 週
  2. 第一條反連:建站後 第 28-42 天才放,且包裝自然(例:「台灣熱門線上娛樂盤點」清單中的一項,不是唯一主角)
  3. 維護頻率:每週 1-2 篇;連結容量每站 5-6 條,逐步用到 60%+,不要一次塞滿
  4. 連結嵌入:contextual 嵌在段落內,不是獨立「友站連結」區塊
  5. Schema:每篇加 Article schema

📌 根據拿到的網域調整主題(給協助者的判斷準則)

  • 網域字面有暗示 → 順著它選:含 travel/trip/hotel → 旅遊;含 tech/gear/review → 3C;含 finance/money/coin → 理財/幣;含 green/eco/design → 生活風格
  • 網域很泛(無明顯字義) → 從上表挑「運動分析 / 數據機率 / 3C 評測」這三個橋接最自然的
  • 避免跟現有 6 站重複:撲克(deckmatt)、戶外裝備(adviseist)、永續旅遊(hipgreenscene)、世足轉播(bolalive77)、世足旅遊(pansurihotel)、防詐設計(plainjanedesigners)已有 → 新站選沒被佔的(理財/幣、數據機率、3C、生活娛樂優先)
  • 主題定了就一致到底:整站文章都圍繞該 niche,不要中途混入其他主題(footprint + 內容信任度)

⑥ 給協助者 AI 的協作提示詞(直接複製貼上)

把下面這段貼給協助者那端的 AI,它就能在正確框架內幫忙產內容/規劃,不會亂搞:

你是 YS89 PBN 網絡的建站助手。我們在建一個全新的 PBN 站,目標是用乾淨、自然的方式,把權重「直連」導向主站 ys89.fun(加速拉抬母站權重)。請嚴格遵守以下規則: 【絕對禁止】 - 不買任何外部連結、老域名外鏈套餐、自動外鏈工具(這會害網站被 Google 懲罰) - 不在內容裡塞滿博弈關鍵字或精確品牌詞 - 不要一次塞多條連結、不要短期暴增(velocity 要慢) 【建站要求】 1. 站的主題是一個「完全正規、與博弈無關」的 niche(例:旅遊、3C 評測、生活風格),要有真實人設與口吻 2. 放任何反連之前,先寫 10-15 篇純 niche 內容養站 4-6 週 3. 之後才在自然的「盤點/清單/比較」類文章中,把指向 ys89.fun 的連結當成「清單中的一項」自然嵌入(連母站首頁/分類頁/深度文,不只連首頁) 4. 錨文字比例嚴格:品牌/裸網址 30%、泛詞 25%、長尾 25%、精確競爭詞 ≤20% 5. 單篇文章最多 1-2 條外連,嵌在段落內文,不做「友站連結」區塊 6. 每站每月最多放 1-2 條連母站的連結(速度慢=安全) 7. 每篇加 Article schema 【我需要你協助的】 (在這裡填:例如「幫我規劃這個旅遊 niche 站的 30 篇文章標題與 10 篇養站內容」、「幫我寫一篇自然嵌入 ys89.fun 連結的盤點文」) 請先問我:這個 PBN 的 niche 主題、人設、要連的目標頁(ys89.fun 哪一頁)是哪些,再開始。

⑦ 建議的第一個任務(給協助者)

  1. 選一個全新 niche + 註冊新網域(換註冊商、開 WHOIS Privacy、虛擬卡付款)
  2. 開專屬 GitHub + CF + email(不碰主帳)
  3. 用上面提示詞讓 AI 規劃 30 篇文章結構 + 先產 10-15 篇養站內容
  4. 部署上線、設定 GSC(固定該站國家 VPN)
  5. 養 4-6 週後回報,再由我們這端決定放第一條連到 ys89.fun 哪一頁、用什麼錨文字

目標頁、確切錨文字、放連結時機與速度,由 YS89 主端統一調度,協助者不自行決定(避免 footprint 失控、velocity 暴增)。
