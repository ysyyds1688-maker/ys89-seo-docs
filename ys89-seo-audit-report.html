🚨嚴重問題（Critical Failures）— 須立即修復
🤖
GEO Schema 漂移（geo-schema-drift）29 頁失敗
頁面上的結構化資料（Schema.org）與實際顯示的內容不符，AI 引擎（ChatGPT、Perplexity、Google AIO）無法正確擷取並引用本站內容。這是影響 GEO（生成式引擎優化）最關鍵的問題。
規則：geo-schema-drift ｜類別：AI/GEO 準備度
修復方式：確保 FAQPage、Article、Organization 等 Schema 中的文字與頁面實際可見內容完全一致，移除僅出現在 ld+json 但正文中不存在的內容。
📝
文字量不足（content-word-count）18 頁失敗
偵測到 18 個頁面的文字字數低於搜尋引擎期望的最低門檻。對於博彩 YMYL 類型的網站，Google 對內容深度要求更高。
規則：content-word-count ｜類別：內容品質
修復方式：每篇文章至少 800 字（建議 1000-1500 字），補充實例、數據、操作步驟等深度內容。針對首頁/分類頁，增加導言段落和常見問答。
📄
重複 Meta Description（htmlval-multiple-descriptions）7 頁失敗
7 個頁面的 HTML 中出現多個 <meta name="description"> 標籤，搜尋引擎只會採用第一個，其他的被忽略，且會造成 HTML 驗證錯誤。
規則：htmlval-multiple-descriptions ｜類別：HTML 驗證
修復方式：檢查主題 header.php，確認 Rank Math 插件和主題本身沒有各自輸出一個 description 標籤。使用 WordPress Customizer 或主題選項移除重複來源。
🏗️
結構化資料必填欄位缺失（schema-required-fields）3 頁失敗
部分頁面的 Schema.org 標記缺少必要欄位（如 Article 需要 author、datePublished；FAQ 需要 acceptedAnswer），Google 不會顯示對應的複合式摘要（Rich Results）。
規則：schema-required-fields ｜類別：結構化資料
修復方式：在 FAQPage Schema 中確保每個 Question 都有完整的 acceptedAnswer。在 Article Schema 中加入 author（Person）、datePublished、image 欄位。
🔗
缺少 Meta Description（core-description-present）2 頁失敗
2 個頁面完全沒有 meta description，搜尋引擎會自動擷取頁面片段作為摘要，通常效果較差，影響點擊率。
規則：core-description-present ｜類別：核心 SEO
修復方式：在 Rank Math 後台為每個頁面填寫 120-160 字元的獨特 meta description，重點放在用戶利益和差異化。
📋
重複 Meta Description 內容（content-duplicate-description）2 頁失敗
2 個頁面的 meta description 內容與其他頁面完全相同，會讓 Google 認為這些頁面是重複內容。
規則：content-duplicate-description ｜類別：內容品質
修復方式：為每個頁面撰寫獨一無二的 description，強調該頁面的特定主題和關鍵字。
⚠️
HTML 結構破損（content-broken-html）2 頁失敗
2 個頁面偵測到格式錯誤的 HTML（如未關閉的標籤、嵌套錯誤等），可能影響搜尋引擎正確解析頁面內容。
規則：content-broken-html ｜類別：內容品質
修復方式：使用 W3C HTML 驗證器（validator.w3.org）找出具體的 HTML 錯誤位置，修正文章編輯器中的格式問題。
📏
URL 過長（url-length）2 頁失敗
2 個頁面的 URL 超過建議的最大長度，可能在搜尋結果中被截斷，影響使用者點擊意願。
規則：url-length ｜類別：URL 結構
修復方式：縮短文章 slug，移除停用詞（的、了、在等），保留最重要的 2-4 個關鍵字。修改後需設定 301 重新導向。
🖼️
背景圖片無法被 SEO 識別（images-background-seo）2 頁失敗
2 個頁面使用 CSS background-image 作為主要內容圖片，搜尋引擎無法讀取其 alt 文字。
規則：images-background-seo ｜類別：圖片
修復方式：將關鍵內容圖片改為 <img> 標籤並加上描述性 alt 屬性；裝飾性圖片才使用 CSS background-image。
📣
Open Graph Description 缺失（social-og-description）1 頁失敗
1 個頁面缺少 og:description 標籤，在 Facebook/LINE 分享時無法顯示摘要說明，降低分享點擊率。
規則：social-og-description ｜類別：社群媒體
修復方式：在 Rank Math 的「社群媒體」標籤中填寫 Facebook 描述，或確保 meta description 自動同步至 og:description。

⚡ 效能優化（影響 Core Web Vitals 排名）
Core Web Vitals 五項指標全部警告（30 頁）
LCP（最大內容渲染）、CLS（累積版面位移）、INP（互動到下一次繪製）、FCP（首次內容繪製）、TTFB（伺服器回應時間）均需改善。這直接影響 Google 搜尋排名。
規則：cwv-lcp / cwv-cls / cwv-inp / cwv-fcp / cwv-ttfb
修復方式：在 Cloudways 啟用 Varnish + Nginx FastCGI Cache；安裝 WP Rocket 或 LiteSpeed Cache；使用 Cloudflare CDN；優化伺服器 TTFB（目標 <200ms）。
字體載入阻塞渲染（perf-font-loading，30 頁）
網頁字體（Google Fonts 等）使用阻塞方式載入，延遲 FCP 和 LCP。
修復方式：在 <link> 加入 rel="preload" as="font" crossorigin；或使用 font-display: swap；考慮自托管字體。
頁面體積過大、JS 未壓縮（29 頁）
perf-page-weight、perf-minify-js、perf-js-file-size 警告影響下載速度，尤其是行動裝置用戶。
修復方式：使用 Autoptimize 或 WP Rocket 壓縮/合併 CSS/JS；啟用 Gzip/Brotli 壓縮；圖片轉換為 WebP 格式。
🔒 安全性強化（影響信任度與 E-E-A-T）
缺少 CSP、Permissions Policy 安全標頭（30 頁）
Content Security Policy 和 Permissions-Policy HTTP 標頭缺失，降低安全評分，也影響 Google 信任指標。
修復方式：在 Cloudways Nginx 設定或 .htaccess 加入安全標頭；或使用 Cloudflare Transform Rules 注入。建議最低配置：X-Content-Type-Options: nosniff、X-Frame-Options: SAMEORIGIN。
SSL 協定版本、Protocol-Relative URL 警告（30 頁）
部分資源仍使用協定相對 URL（//domain/path），建議全部改用明確的 https://。
修復方式：在 wp-config.php 強制 HTTPS；使用 Better Search Replace 將資料庫中的 http:// 改為 https://。
🤖 AI/GEO 準備度（影響 ChatGPT/Perplexity 引用）
缺少 llms.txt 檔案（geo-llms-txt，30 頁）
llms.txt 是新興的 AI 機器人指引標準，告訴 ChatGPT、Claude 等 AI 爬蟲哪些內容可以被訓練和引用。目前缺少此檔案。
修復方式：在網站根目錄建立 /llms.txt，說明網站用途、可引用內容清單、聯絡方式。參考格式：https://llmstxt.org/
語義化 HTML 不足（geo-semantic-html，17 頁）
頁面使用過多 <div> 而非語義化標籤（<article>、<section>、<main>、<aside>），AI 引擎較難理解內容結構。
修復方式：在主題模板中將文章容器改為 <article>，側欄使用 <aside>，頁首使用 <header>，主體使用 <main>。
內容結構未針對 AI 優化（geo-content-structure，12 頁）
AI 引擎偏好具有清晰問答結構、清單、表格的內容，目前部分頁面缺乏這些結構。
修復方式：每篇文章加入「常見問題 FAQ」段落（已完成 FAQPage Schema）；使用有序/無序清單呈現步驟；加入比較表格。
👤 E-E-A-T 信任度（影響 YMYL 類網站排名）
缺少作者專業資訊（eeat-author-expertise，30 頁）
博彩類網站屬於 YMYL（Your Money or Your Life）內容，Google 對作者資訊要求極高。目前文章缺少作者 byline 和專業背景說明。
修復方式：建立作者 WordPress 帳號，填寫詳細的個人簡介（含博彩經驗說明）；在文章中顯示作者資訊方塊；建立作者頁面。
缺少引用來源（eeat-citations，30 頁）
文章中沒有引用可信賴的外部資料來源（如官方規則、研究報告等），降低內容可信度。
修復方式：在文章中適當引用官方來源（如台灣彩券、各大運動聯盟官網等）；使用 rel="nofollow" 外部連結。
缺少關於我們頁面和編輯政策（29/28 頁）
eeat-about-page（29頁）和 eeat-editorial-policy（28頁）缺失，Google 的 Quality Rater 會優先評估這些頁面。
修復方式：建立「關於我們」頁面說明網站定位、團隊背景；建立「編輯方針」說明內容審核流程、免責聲明。
♿ 無障礙設計（影響使用者體驗與 SEO）
缺少跳過導覽連結（a11y-skip-link）、地標區域（a11y-landmark-regions）、觸控目標大小（a11y-touch-targets）
30 頁全部觸發以上三項警告，影響螢幕閱讀器使用者和行動裝置用戶體驗。
修復方式：在 header.php 加入「跳到主要內容」連結；確保 <main> <nav> <header> <footer> 地標標籤存在；按鈕/連結最小觸控面積 44×44px。
圖片缺少尺寸、未使用現代格式、未設定延遲載入（27 頁）
images-dimensions、images-modern-format、images-responsive 警告，影響 CLS 和頁面載入速度。
修復方式：所有 <img> 加入 width/height 屬性；安裝 WebP Express 插件自動轉換格式；加入 loading="lazy"（非首屏圖片）。
