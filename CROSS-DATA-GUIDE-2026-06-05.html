③ 交叉比對 = 檢查每一棒「接得順不順」

把相鄰兩段的數字相除，看有沒有「漏接」。每段給你「正常 / 出事」怎麼讀：
①→② 點擊接收　＝ lihi點擊 ÷ FB點擊
🟢 接近 100%：FB 說的點擊，lihi 都有接到。
🔴 明顯偏低：FB 灌的點擊沒進 lihi → 可能假點擊或連結錯。（別急著怪落地頁）
②→③ 跳轉到站　＝ GA4瀏覽 ÷ lihi點擊
🟢 ≥85%：跳轉順、頁面有載出來。
🔴 偏低：lihi 接到卻沒到站 → 跳轉失敗 / 頁面太慢 / GA4 沒載。技術問題，不是內容問題。
③→④ 到站點 CTA　＝ outbound ÷ GA4瀏覽
🟢 越高越好：頁面有說服力。
🔴 偏低：人來了不點 → 落地頁內容 / CTA 不夠力。要改頁。
④→⑤ 點了到註冊　＝ proxy註冊 ÷ outbound
🟢 健康：跳過去的人多數有註冊。
🔴 偏低：點出去卻沒註冊 → 平台註冊頁卡關，或 proxy 沒帶過去（查 lihi / 落地頁帶碼）。
⑤ ＞ ④（怪現象）
註冊比 outbound 還多 → 有非廣告來源也用同一個 proxy → proxy 不夠純，要更細的碼才分得開。

④ 四個關鍵指標：怎樣算好、該做什麼

CPC 每次點擊成本
花費 ÷ FB點擊
流量貴不貴。
太高 → 換素材 / 換受眾，或 CTR 太低拉高了成本。
各段轉換率
相鄰兩段相除
漏斗哪一段在漏。
先補「最低的那一段」，補一段勝過全部微調。
CPA 每註冊成本
花費 ÷ 註冊
抓一個會員多少錢。
兩落地頁比 CPA → 預算往低的加，高的收。
ROAS 廣告投報 ⭐
入金額 ÷ 花費
賺不賺錢的終極數字。
≥2x 賺　1–2x 回本　<1x 虧 → <1 就該收或改。

⑤ 看到這樣 → 代表什麼 → 你該做什麼

你看到代表動作
點擊多、到站少跳轉/技術漏（①→②或②→③低）查 lihi 連結、落地頁載入速度，先別動文案
到站多、點CTA少落地頁不夠力（③→④低）改標題/CTA/版位，做 A/B
點CTA多、註冊少平台註冊卡關 或 proxy 沒帶（④→⑤低）查 proxy 有沒有帶到、平台註冊流程
CPA 偏高但 ROAS>1抓客貴，但客人有付錢、還賺可續投，同時想辦法降 CPA
ROAS < 1花的比賺的多 → 虧收掉這組，或大改素材/受眾/落地頁
某落地頁 CPA 低 + ROAS 高這頁/這素材最會賺預算往它加碼，複製它的做法

⑥ 常見誤讀（會害你判斷錯）

  • 用單日硬對帳 → 有人今天點、明天才註冊，單日永遠對不平。一律用「週」對。
  • 時區沒對齊 → FB / GA4 / 平台後台時區可能不同，先全部換台灣時間再比。
  • 只看點擊數多就高興 → 點擊多但 ROAS<1 還是虧。永遠以 ROAS 收尾判斷。
  • 素材層硬要對註冊 → 現在 proxy 只分到「落地頁層」，多素材共用一碼分不出。要對到素材層 → 要加動態 proxy。
  • 把『地推/水軍』當 FB 受眾 → 那是「來源管道」，用 utm_source 分；FB 受眾是廣泛/興趣/再行銷。
